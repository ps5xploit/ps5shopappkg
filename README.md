- **PS5 max firmware:** 13.60
- **DPI v2 / Direct Package Installer (port 12800)** must be running.

You have **two options**:

### Option A – You already use etaHEN
Enable **Services → Direct Package Installer V2 (DPI 12800)** inside etaHEN. Done.

### Option B – You DON'T use etaHEN
Grab the **standalone DPIv2 payload** and load it. No etaHEN required. 

**➡️ Download here:** [DPIv2.elf (latest release)](https://github.com/ps5xploit/ps5shopappkg/releases/latest)

How to use it:

1.Start kstuff on your PS5.

2. Send `DPIv2.elf` with your payload injector or payloadmanager

3. Open https://ps5shopappkg.pages.dev in your browser.
